# 🖥️ Консоль Linux: Шпаргалка по эффективности

## Почему консоль, а не GUI?
1. **Компонуемость (Unix-пайп `|`)**: Маленькие утилиты (`grep`, `sort`, `awk`) соединяются в цепочки. Не нужно помнить одну сложную команду, нужно уметь соединять простые шаги.
2. **Автоматизируемость**: Любую последовательность действий можно сохранить в скрипт, положить в Git и воспроизвести на 100 серверах без ошибок.
3. **Надёжность связи**: SSH-сессия передаёт только текст. Она работает там, где графический удалённый рабочий стол (RDP/VNC) уже давно отвалился из-за плохого интернета.

## ⚡ Горячие клавиши (Must Know)
| Сочетание | Действие | Аналог / Примечание |
| :--- | :--- | :--- |
| **`Tab`** | Автодополнение команды или пути | Нажимай после каждых 2-3 символов |
| **`Tab` + `Tab`** | Показать все возможные варианты | Если совпадений несколько |
| **`Ctrl + R`** | **Обратный поиск по истории** | Начни вводить часть команды (самый мощный инструмент!) |
| **`Ctrl + C`** | **Принудительное прерывание** | Аварийный выход из зависшей или долгой команды |
| **`Ctrl + D`** | Завершение сессии | Аналог команды `exit` или EOF |
| **`Ctrl + L`** | Очистка экрана | Аналог команды `clear` |
| **`Ctrl + A`** | Переход в **начало** строки | Удобно для исправления опечаток в начале |
| **`Ctrl + E`** | Переход в **конец** строки | |
| **`Ctrl + W`** | Удалить одно слово перед курсором | |
| **`Ctrl + U`** | Удалить всё от курсора до начала строки | |

## 📋 Копирование и вставка в терминале
- **Копировать**: `Ctrl + Shift + C`
- **Вставить**: `Ctrl + Shift + V`
- **Linux-фишка (Selection Buffer)**: Просто выдели текст мышью (он уже в буфере) и нажми **среднюю кнопку мыши (колёсико)** для вставки. Работает быстрее любых клавиш.

## 🧠 Философия и лучшие практики
1. **Ошибки — это нормально**. Сообщения `command not found`, `No such file` или `Permission denied` не ломают систему. Они просто говорят, что нужно поправить ввод. Экспериментируй смело.
2. **Многозадачность через вкладки**. Держи разные задачи в разных вкладках терминала:
   - Вкладка 1: Редактирование конфига (`sudo nvim ...`)
   - Вкладка 2: Перезапуск службы (`sudo systemctl restart ...`)
   - Вкладка 3: Мониторинг логов в реальном времени (`tail -f /var/log/...`)
3. **История — твой друг**. Команда `history` показывает всё. Не печатай одно и то же дважды, используй стрелки вверх/вниз или `Ctrl+R`.
