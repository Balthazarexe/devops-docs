# Neovim Cheat Sheet 🚀

## 1. Режимы (Modes)
- `Esc` или `Ctrl+[` — вернуться в **Normal** режим (делай это рефлекторно после любого действия).
- `i` — Insert (вставка перед курсором).
- `a` — Append (вставка после курсора).
- `v` — Visual (выделение символов).
- `Ctrl+v` — Visual Block (выделение столбцом, идеально для комментирования строк в конфигах).
- `:` — Command-line (ввод команд).

## 2. Навигация (Движение без стрелок!)
- `h`, `j`, `k`, `l` — влево, вниз, вверх, вправо.
- `w` — слово вперёд (word), `b` — слово назад (back), `e` — конец слова (end).
- `0` — начало строки, `^` — первый непробельный символ, `$` — конец строки.
- `gg` — в начало файла, `G` — в конец файла.
- `Ctrl+u` / `Ctrl+d` — полстраницы вверх / вниз.
- `Ctrl+o` / `Ctrl+i` — прыжок назад / вперёд по истории перемещений (мастхэв при чтении кода/логов).

## 3. Редактирование (Магия удаления и изменения)
- `x` — удалить символ под курсором, `X` — символ перед курсором.
- `d` + движение — удалить (например, `dw` — удалить слово, `d$` — до конца строки, `dd` — всю строку).
- `c` + движение — изменить (удалить и перейти в режим вставки). `cw` — изменить слово.
- `y` + движение — копировать (yank). `yy` или `Y` — копировать строку.
- `p` — вставить после курсора, `P` — вставить перед курсором.
- `u` — отменить (undo), `Ctrl+r` — повторить (redo).

### 🔥 "Guru" комбинации (Change Inner)
- `ciw` — изменить слово под курсором (стирает слово и даёт писать новое).
- `ci"` — изменить всё внутри кавычек (идеально для правки конфигов или JSON).
- `ci(` или `ci)` — изменить всё внутри скобок.

## 4. Файлы и буферы
- `:w` — сохранить, `:q` — выйти, `:wq` или `ZZ` — сохранить и выйти, `:q!` — выйти без сохранения.
- `:e <путь>` — открыть файл (edit).
- `:bn` — следующий буфер, `:bp` — предыдущий буфер, `:bd` — закрыть текущий буфер.

## 5. Поиск и замена
- `/текст` — поиск вперёд, `?текст` — поиск назад.
- `n` — следующее совпадение, `N` — предыдущее.
- `:%s/старое/новое/gc` — заменить "старое" на "новое" во всём файле (`g`) с подтверждением каждой замены (`c`).

## 6. Секретное оружие
- `.` (точка) — повторить последнее действие редактирования (невероятно ускоряет работу).
- `:help <тема>` — встроенная справка (например, `:help motion.txt`). Настоящие гуру читают хелп, а не StackOverflow.
- `V` (большая) + `j/k` + `I` + `#` + `Esc` — быстро закомментировать несколько строк в конфиге (Visual Line режим).
